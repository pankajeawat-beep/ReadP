# PDF Audio Reader – build the APK (no Android Studio needed)
1. Create a free GitHub account and a new repository.
2. Upload everything in this folder (keep the hidden `.github` folder, `www`, `package.json`, `capacitor.config.json`).
3. Open the repo's **Actions** tab -> **Build APK** -> wait ~5 min.
4. Open the finished run, download the **PDF-Audio-Reader-apk** artifact, unzip, and install `app-debug.apk` on your phone (allow "install unknown apps").
